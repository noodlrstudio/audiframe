# Contributing

Open issues or pull requests with a concrete interoperability problem. Wire
changes begin as an RFC in `spec/rfcs/` with compatibility impact, security
boundaries, migration, limits and success/error fixtures. SDKs cannot secretly
change the standard. No ecosystem account, approval badge or SDK is required.

Run `npm ci`, `npm run check`, `npm test`, `npm run size`, and all three browser
runners. Keep modules below 500 lines. Keep musical UIs calm; use semantic labels
and tooltips. Report browser timing and audible output separately.

Contributions to implementation are under MIT; specification contributions are
under CC BY 4.0. By contributing you confirm you can license your contribution
and agree to these terms. This is not an additional patent license; a reviewed
contribution/patent policy is a stable 1.0 gate. Maintainers resolve draft RFCs
in public and record wire changes in CHANGELOG.md. No standards-body endorsement.
